# Stalzone Market

Android-приложение для отслеживания цен на аукционе Stalzone.
Данные берутся из [официального API EXBO](https://eapi.stalzone.com/docs),
названия и иконки — из открытой базы [EXBO-Studio/stalzone-database](https://github.com/EXBO-Studio/stalzone-database).

## Возможности

- Поиск любого предмета по названию и категориям.
- Избранное с минимальной ценой выкупа, числом лотов и средней ценой продаж.
- Страница предмета: текущие лоты (время, ставка, выкуп), сортировка, график и история продаж.
- Регионы RU, EU, NA, SEA, NEA.
- Уведомление, когда выкуп за штуку опускается ниже заданного порога (проверка в фоне ~раз в 15 минут).

## Ключи API

Нужны собственные `client_id` и `client_secret`: зарегистрируйте приложение в EXBO
через Telegram-бота «Stalzone API» (`/newapp`) и дождитесь одобрения.
Ключи вводятся в приложении на вкладке «Настройки» и хранятся только на телефоне —
в репозитории их нет.

## Установка

Скачайте `.apk` со страницы [Releases](../../releases).

## Сборка

```
./gradlew assembleRelease
```

Каждый push в `main` собирает APK в GitHub Actions. Релиз: Actions → Build → Run workflow → версия, например `v1.0.0`.
